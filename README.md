# CV Online — Ramdhan Bayu Prasetyo

Website CV pribadi yang saya buat sebagai media untuk memperkenalkan latar belakang, keahlian, minat karier, dan pengalaman saya. Proyek ini juga menjadi bagian dari proses belajar saya dalam mengembangkan website.

## Tentang Proyek

Halaman CV disusun menggunakan HTML dan CSS tanpa framework. Saya memisahkan struktur konten dan aturan tampilannya agar lebih mudah dibaca dan dikembangkan.

Fokus pengerjaan proyek ini meliputi:

- Menyusun informasi CV dalam bagian profil, kontak, keahlian, minat karier, pengalaman, dan pendidikan.
- Mengatur tata letak agar menyesuaikan ukuran layar desktop maupun ponsel.
- Menggunakan palet gelap dengan aksen ungu dan bentuk geometris.
- Menambahkan tautan WhatsApp serta foto profil.
- Menyiapkan aturan tampilan untuk mencetak CV atau menyimpannya sebagai PDF.

## Teknologi

- HTML5 untuk struktur halaman.
- CSS3 untuk tata letak, warna, tipografi, dan tampilan responsif.
- Google Fonts untuk tipografi.

## Menjalankan Proyek

1. Unduh atau salin seluruh file proyek ke satu folder.
2. Pastikan `foto-profil.jpg` dan `LogoWA.png` berada di folder yang sama dengan file HTML.
3. Buka `Index.html` menggunakan browser.

## Struktur File

```text
.
├── Index.html       # Struktur dan isi CV
├── style.css        # Gaya dan tata letak halaman
├── foto-profil.jpg  # Foto profil
└── LogoWA.png       # Logo WhatsApp dengan latar transparan
```
